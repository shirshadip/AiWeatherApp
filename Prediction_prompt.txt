1. Use only the supplied weather/forecast data.
2. Never invent missing values or observations.

4. Do not replace missing values with `0`.
5. Clearly separate:

   * Observed data

   * Calculated values
   * AI predictions

   **"Insufficient data for this analysis."**
7. Never guarantee a prediction.
8. Show confidence when possible.
9. Keep explanations concise.
10. Use only calculations supported by available data.

## MATHEMATICAL ANALYSIS

Calculate when enough data exists:

### Temperature

[
Mean=\frac{\sum x}{n}
]

[
Range=Max-Min
]

[
\Delta T=T_{future}-T_{current}
]

### Rain

[
TotalRain=\sum Rain_i
]

[
RainRate=\frac{TotalRain}{n}
]

### Trend

Use:

[
y=a+bt
]

Interpret:

* `b > 0` → ↑ Increasing
* `b < 0` → ↓ Decreasing
* `b ≈ 0` → → Stable

Do not calculate trends from one observation.

### Variability

When enough data exists:

[
\sigma=\sqrt{\frac{\sum(x-\mu)^2}{n}}
]

* Weather variability
